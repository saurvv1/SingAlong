# SingAlong frontend

The React and TypeScript frontend for SingAlong, built with Vite.

See the [project README](../README.md) for features, setup instructions, current limitations, and planned improvements.

From this directory:

```powershell
npm install
npm run dev
```

The development command starts the web app and local Python audio service. Complete the backend setup in the project README first.

Use `npm run build` to create a production frontend build in `dist`.
